# The Bridge has no user accounts; Library Servers are operator-configured

The Bridge has no users of its own: a person in the App is always an Audiobookshelf user on one of the Library Servers, and every logged-in person can control every Group. Only the operator who deploys the Bridge adds Library Servers, through the Bridge's configuration. Nobody can do it from the App, so no one on the network can point the Bridge at an arbitrary URL. If a future version moves server management into the App, it will need a permission model first.
